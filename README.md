# 원드라마 광고 집행 관리

원드라마(drama.onestore.co.kr) 2026년 12월 광고 집행을 관리하는 사이트입니다. 설치나 빌드 없이 `index.html`만 열면 됩니다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 대시보드 | 지금 시기, 집행액, 첫 재생, 첫 재생당 비용, 끄기 후보 알림, 다음 할 일 |
| 체크리스트 | 집행 전 준비 / 시험 기간 / 메인~마무리 할 일. 항목 추가 가능 |
| 예산 | 매체별·시기별 하루 예산 수정, 계획 대비 집행액 |
| 작품 | 광고 후보 129편에서 3~5편 고르기, 작품코드(w01~) 배정, 랜딩 주소 |
| 소재 | 작품별 소재 8종의 상태와 검수, 주간 교체 소재 추가 |
| 링크 태그 | utm 링크 자동 생성, 이름 규칙, 복사·CSV |
| 광고 등록 | 광고 문구·키워드·영상 ID를 채워 매체별 대량 등록 파일(CSV) 내려받기, 열 맞추기, 등록 상태 관리 |
| 성과 리포트 | 날짜·매체·소재별 성과 입력, 매체별/소재별/작품별/날짜별/주간 집계, 끄기 후보 표시 |
| 운영 가이드 | 운영 기준, 매체별 메모, 용어 |
| 데이터 | 백업 파일 내보내기·가져오기, 예시 데이터 |

## 실행

```bash
python -m http.server 5173
```

브라우저에서 `http://localhost:5173`을 엽니다. `index.html`을 직접 열어도 됩니다.

주소에 `?today=2026-12-05`를 붙이면 그 날짜 기준 화면을 미리 볼 수 있습니다.

## 데이터

- 입력한 내용은 **그 브라우저의 localStorage에만** 저장됩니다. 서버로 보내지 않습니다.
- 다른 사람과 나누거나 다른 컴퓨터로 옮기려면 「데이터」 화면에서 백업 파일을 내보내고 가져옵니다.
- 계획 값(예산, 시기, 매체, 체크리스트)은 `js/plan.js`에 있습니다.
- 작품 목록은 `js/works-data.js`입니다. 콘텐츠 목록 엑셀이 바뀌면 다시 만듭니다.

```bash
python tools/build_data.py 원드라마_콘텐츠_목록.xlsx
```
